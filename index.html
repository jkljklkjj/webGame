== TERMINAL ARCADE ============================================== v1.2

字符网格驱动的小游戏合集 · 12 个游戏 · 4 个支持同屏双人 · 零依赖 · 一个 div 就能接进任何页面

接入方式

三种都可以，选一个就行。

<!-- 1. 最简单：一行标签，自动挂载 -->
<link rel="stylesheet" href="styles.css">
<div data-arcade></div>
<script src="embed.js"></script>

<!-- 指定启动的游戏和高度 -->
<div data-arcade data-game="hockey" data-height="520" data-muted></div>
// 2. ES module：自定义挂载点
import { mount } from './src/main.js';

const arcade = mount('#arcade', { game: 'snake' });
// 返回值就是引擎实例
arcade.startGame(4);   // 直接切到第 5 个游戏
arcade.destroy();      // 卸载，解绑所有监听
// 3. iframe（完全隔离样式时）
<iframe src="index.html" width="860" height="640" style="border:0"></iframe>
// 4. 单文件构建：没有服务器也能开（双击 dist/demo.html）
$ npm run build
$ open dist/demo.html

// 产物三件套，随便拷走：
dist/terminal-arcade.js     // 103 KB，一个 IIFE，无 import
dist/terminal-arcade.css
dist/demo.html              // 全内联，离线可跑

触屏：滑动 = 方向键，轻点 = 空格；乒乓和冰球可以直接用手指拖。

双人

在菜单里按 ←→ 切换单人 / 双人（标题栏会显示 1 PLAYER 或 2 PLAYERS）， 选择会按游戏记住。两个人的键位完全分开：

移动动作
P1W A S DF / 空格 / 左 Shift
P2↑ ↓ ← →Enter / 右 Shift / 小键盘 0

触屏也能双人：先按下的手指归 P1，第二根归 P2。暂停层会同时列出两人的键位。

自己加一个游戏

游戏 = 一个对象 + 一个 create()。引擎只要求 update(dt) 和 render(screen)。

import { register, GAMES } from './src/main.js';

register({
  id: 'dots',
  name: 'DOTS',
  cn: '点阵',
  desc: '按空格撒点',
  keys: ['空格 撒一个点'],

  create(api) {
    const { screen, input, audio } = api;
    const pts = [];

    return {
      reset() { pts.length = 0; },

      update(dt) {
        if (input.pressed('space')) {
          pts.push({ x: api.w >> 1, y: api.h >> 1 });
          audio.blip();
          api.setStatus(`点 ${pts.length}`);
        }
      },

      render(s) {
        s.clear('bg');
        s.box(0, 0, api.w, api.h, 'accent2');
        pts.forEach((p, i) => s.put(p.x + i, p.y + i, '*', 'accent'));
      },
    };
  },
});

API 速查

名字说明
screen字符缓冲：put / write / fill / box / hline / vline / writeCenter / writeRight / clear
input合并层：isDown(n) pressed(n) axisX/axisY() dir() pointAt(n)
input.p1 / p2玩家层：同样的接口，只认自己那套键（up down left right fire）
players本局人数 1 或 2，在 reset() 里读
audiobeep(freq, dur, type) blip/hit/bounce/score/win/lose
w / h可用网格尺寸（80 × 35，最后一行是状态栏）
setStatus(s)写进底部状态栏
over(msg) / won(msg)结束本局并弹出结果层
saveBest(n)刷新最高分（localStorage）
restart() / exit()重开 / 回菜单
dt固定步长 1/60 秒，物理直接按秒算
